# Our Hindi words

The app's own terms in Hindi, said one way in every string. **A machine
draft** (polyglotic-hq 294, 2026-11-13, by Claude) for a native speaker's
review: correct a term here first, then every string using it.

How the Hindi is written: everyday Hindi as phones and Windows use it,
English loanwords where Hindi speakers use them in software (कैप्शन,
ऐप, सेटिंग), polite आप with -एँ commands (चुनें, करें); Western digits;
drawn in Nirmala UI (`style.SCRIPT_FACES`); Polyglotic, Plus, Anki,
Windows, HSK stay as they are.
