# Our Czech words

The app's own terms in Czech, said one way in every string. **A machine
draft** (polyglotic-hq 294, 2026-11-13, by Claude) for a native speaker's
review: correct a term here first, then every string using it.

How the Czech is written: polite plural (vykání) with imperatives as
Windows writes them (Klikněte, Zvolte); three plural forms (1; 2-4; 5 and
more); a name in a placeholder ({app}, {language}) put where its case
doesn't change (after a colon or a dash) where Czech grammar would
otherwise need it declined; Polyglotic, Plus, Anki, Windows, HSK stay as
they are.
