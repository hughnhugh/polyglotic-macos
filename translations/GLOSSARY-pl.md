# Our Polish words

The app's own terms in Polish, said one way in every string. **A machine
draft** (polyglotic-hq 294, 2026-11-13, by Claude) for a native speaker's
review: correct a term here first, then every string using it.

How the Polish is written: "ty", friendly, as the English is; „cudzysłów";
counts in three forms (1 napis, 2 napisy, 5 napisów); short forms where a
button has little room; Polyglotic, Plus, Anki, Windows, HSK stay as they
are.
