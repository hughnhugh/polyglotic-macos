# Korean UI copy for 0.1.12

These 20 phrases remain drafts for a native Korean reader to check in context. The Korean text appears in the app. In particular, check whether the two long-line options tell you where the translation will appear, and whether the Learning labels make clear which words are linked or highlighted.

| English source | Korean in 0.1.12 | Alternative | Where to check |
|---|---|---|---|
| Display new lines | 줄마다 번역 표시 | 원문·번역 한 줄씩 | Caption window settings → Long lines. Each original row is followed by its translation. |
| Grouped | 원문과 번역 따로 | 같은 언어끼리 묶기 | Caption window settings → Long lines. The original rows are grouped together, followed by the translation. |
| Fill the width, in every window: captions run on in lines as wide as the window, each line of what was said over its translation | 모든 창에서 자막을 창 너비까지 이어서 표시하고 원문 각 줄 바로 아래에 번역을 놓습니다. | 모든 창에서 원문을 창 너비까지 채우고 각 줄 아래에 번역을 표시합니다. | Caption window toolbar → Fill the width tooltip. |
| Caption actions | 자막 저장 및 복사 | 자막 작업 | Caption window → hovered caption. Accessible label for actions on a single caption. |
| Show caption info | 자막 정보 표시 | 언어와 출처 표시 | Caption window settings. Shows the language and audio source above the caption. |
| Also caption everything else | 나머지 소리도 자막 표시 | 나머지 소리도 별도 자막으로 | Home → What to caption. The switch adds a separate window for the audio outside the selected app. |
| not playing | 재생 중 아님 | 재생 안 함 | Home → app row. The status describes an app with no audio playing. |
| Them {average} avg · {peak} peak | 상대 (분당 단어 수) 평균 {average} · 최고 {peak} | 상대 분당 평균 {average}단어 · 최대 {peak}단어 | Home → Last session. Two values for speaking pace. |
| Hold a key to type it | 키를 눌러 상대방 말 입력 | 키를 누른 채 자막 입력 | Settings → Shortcuts → Type what they said. The text can come from the caption window or from speaker audio. |
| Words beyond your level | 내 수준을 넘는 단어 | 내 수준보다 어려운 단어 | Learning → Word links. The cutoff can be based on word frequency or the learner’s level estimate. |
| Link words after | 단어 연결 기준 | 이 기준을 넘는 단어만 연결 | Learning → Word links. The selected rank or level is the cutoff. |
| New words to highlight | 강조할 새 단어 | 새 단어 강조 범위 | Learning → Word introductions. The adjacent control chooses how many likely new words to highlight. |
| Repeated words | 자주 듣는 단어 | 여러 번 들은 새 단어 | Words → Repeated words. The list is for new words heard several times. |
| Every word you have heard, saved or given a status. | 들었거나 저장했거나 상태를 지정한 모든 단어입니다. | 듣기, 저장 또는 상태 표시로 기록된 모든 단어입니다. | Words → All words. Any of the three actions is enough to include a word. |
| Full phrase not found | 구절 전체의 사전 항목 없음 | 사전에 구절 전체가 없음 | Lookup card. Individual words or a fallback meaning may still be available. |
| Chinese equivalent | 같은 뜻의 중국어 | 대응하는 중국어 표현 | Lookup card → parts list. Check whether the heading works above the Chinese entry for a Japanese lookup. |
| Fade after silence | 말소리가 없으면 자막 숨기기 | 무음 뒤 자막 숨기기 | Settings → caption appearance, and saved preset details. The control sets a timeout without speech. |
| Pause hidden windows after | 숨긴 창의 일시 중지 시간 | 숨긴 창 일시 중지까지 | Settings → caption appearance. Capture pauses after the window has been hidden for the selected duration. |
| Live lines below, earlier above | 실시간 자막은 아래, 이전 자막은 위 | 최신 자막은 아래, 이전 자막은 위 | Settings → caption timing, and saved preset details. The bottom area follows current speech. |
| Make a suggestion | 개선 제안 | 의견 보내기 | Report or suggestion dialog. Check the tone on the dialog tab or title. |
