# Turkish interface wording for native review

Try these labels in the 0.1.12 interface. Check whether the wording makes the action clear and fits the control at normal size. The table gives the current catalog wording and one candidate for each item. “Link words after” remains unfinished while the frequency cutoff wording is open.

| Context | English | Turkish | Alternative | Where to check |
|---|---|---|---|---|
| Panels, Presets | Faint ahead | Önde soluk | Gelecek kelimeler soluk | Settings → Timing and the saved preset summary. Upcoming words appear faintly until their turn. |
| Panels, Presets | Acquisition | Edinim | Önce orijinal | Settings → Timing, reading order. The spoken clause appears before its translation. |
| Panels, Presets | Follow | Takip | Önce çeviri | Settings → Timing, reading order. The translation leads and the original is smaller. |
| CaptionWindow, Panels, Presets | Quiet view | Sakin görünüm | Sade görünüm | Caption menu and Settings. The style dims the text and emphasizes selected words in blue. |
| CaptionWindow, Panels | Words at your edge | Sınırındaki kelimeler | Seviyene yakın yeni kelimeler | Quiet view options in the caption menu and Settings. This chooses words in the learning window. |
| SettingsPopover | Display new lines | Satır satır | Satır satır çeviri | Caption settings → Long lines. Each original row is followed by its translation. |
| SettingsPopover | Grouped | Gruplu | Dile göre grupla | Caption settings → Long lines. All original rows appear before the translation rows. |
| SettingsPopover | Lines already in {language} | {language} dilindeki satırlar | Satırlar zaten {language} dilinde | Caption settings, second-language row. Try it after choosing a target language. |
| Panels, Presets | Live lines below, earlier above | Canlı satırlar altta, öncekiler üstte | Yeni satırlar altta, eskiler üstte | Settings → Appearance and the preset summary. Check the bottom edge as captions arrive. |
| SettingsPopover, Presets, Panels | Panel: how solid | Panel opaklığı (Panels: Panel: dolgunluk) | Panelin opaklığı | Caption settings percentage slider, preset summary and Settings → Appearance. Check whether the label makes the 100% end clear. |
| Learning | Words beyond your level | Seviyenin üstündekiler | Seviyenin üstündeki kelimeler | Learning → Word links, middle option beside Every word and Off. |
| Learning | Link words after | Kelime bağları için eşik | Kelime bağlarının başlangıcı | Learning, frequency rank dropdown below Word links. It sets the cutoff after which words receive links. |
| Learning | New words to highlight | Vurgulanacak yeni kelimeler | Vurgulanacak kelime sayısı | Learning, selector for how many new words above the current level are highlighted. |
| Words | Repeated words | Sık duyduğun kelimeler | Sık duyduğun yeni kelimeler | Words, section for unfamiliar words ordered by how often they were heard. |
| Words, Learning | Mark known | Bilinen olarak işaretle (Learning: Bilinen işaretle) | Biliyorum | Words, an individual status action. Learning, the button that applies a bulk frequency cutoff. |
| CaptionWindow | Caption actions | Altyazı işlemleri | Altyazı seçenekleri | Accessible name for the Save and Copy buttons shown when hovering a caption row. |
| DesktopApp | Help build Polyglotic… | Polyglotic'i geliştirmeye yardım et… | Polyglotic'e katkıda bulun… | Feedback menu. Opens the invitation to work with Polyglotic. |
| Home | Also caption everything else | Diğer tüm seslere de altyazı ekle | Diğer seslere de altyazı ekle | Audio source picker with one app selected. The remaining audio gets its own caption window. |
| Account | Redeem a code | Kodu kullan | Davet kodunu kullan | Account action that opens the code redemption flow. Check next to the form heading. |
| Panels | Words linked | Bağlanacak kelimeler | Hangi kelimeler bağlanır? | Word links settings. The segmented control chooses key words only or most words. |
