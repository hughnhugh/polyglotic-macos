# Czech interface review for 0.1.12

These 20 entries are the highest priorities for a native Czech reader. Six
still carry Qt's draft flag. Each entry has Czech text in the app.

| Where it appears | English | Current Czech | Alternative | What to check |
|---|---|---|---|---|
