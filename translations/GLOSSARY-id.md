# Our Indonesian words

The app's own terms in Indonesian, said one way in every string. **A
machine draft** (polyglotic-hq 294, 2026-11-13, by Claude) for a native
speaker's review: correct a term here first, then every string using it.

How the Indonesian is written: "kamu", friendly, as the English is (a
reviewer may prefer "Anda"); "subtitle", the everyday word (the formal one
is "takarir"); Polyglotic, Plus, Anki, Windows, HSK stay as they are.
