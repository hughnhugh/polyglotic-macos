# Our Indonesian words

The app uses `kamu` and concise action verbs. Keep Polyglotic, Plus, Anki,
Windows and HSK as written. The 0.1.12 refresh carries forward the terminology
from the 2026-11-24 pass. See [the native review notes](review/review-id.md)
for wording to try in the interface.
