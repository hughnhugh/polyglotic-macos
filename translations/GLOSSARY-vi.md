# Our Vietnamese words

The app's own terms in Vietnamese, said one way in every string. **A
machine draft** (polyglotic-hq 294, 2026-11-13, by Claude) for a native
speaker's review: correct a term here first, then every string using it.

How the Vietnamese is written: "bạn", friendly, as the English is;
"ngoặc kép"; Polyglotic, Plus, Anki, Windows, HSK stay as they are.
