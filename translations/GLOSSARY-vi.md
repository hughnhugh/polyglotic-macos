# Our Vietnamese words

The app's own terms in Vietnamese, said one way in every string. Critically
reviewed for project 873 on 2026-11-24 and refreshed against 0.1.12 on
2026-11-26. The native review shortlist is in [review-vi.md](review/review-vi.md).
Correct a term here first, then every string using it.

How the Vietnamese is written: "bạn", friendly, as the English is;
"ngoặc kép"; Polyglotic, Plus, Anki, Windows, HSK stay as they are.
