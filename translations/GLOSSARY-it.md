# Our Italian words

The app's own terms in Italian, said one way in every string. **A machine
draft** (polyglotic-hq 294, 2026-11-13, by Claude) for a native speaker's
review: correct a term here first, then every string using it.

How the Italian is written: "tu", friendly, as the English is and as
most apps are; «virgolette»; Polyglotic, Plus, Anki, Windows, HSK stay as
they are.
