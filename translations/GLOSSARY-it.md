# Our Italian words

The app's own terms in Italian, said one way in every string. **Reviewed draft**
(polyglotic-hq 852, 2026-11-24) for a native speaker's final sign-off: correct a
term here first, then every string using it.

How the Italian is written: "tu", friendly, concise, imperative 2nd-person
singular on buttons (*Salva*, *Apri*, *Chiudi*, *Sottotitola*), as standard in
Italian desktop apps; «virgolette» for quotes; straight apostrophe `'`; proper
Italian punctuation (`:`, `;`, `,`) rather than spaced hyphens (` - `);
Polyglotic, Plus, Lite, Standard, Premium, Anki, Windows, macOS, Linux, HSK,
Home, Account stay as they are.
