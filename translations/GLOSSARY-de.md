# Our German words

The app's own terms in German, said one way in every string. **A machine
draft** (polyglotic-hq 294, 2026-11-13, by Claude) for a native speaker's
review: correct a term here first, then every string using it.

How the German is written: "du", friendly, as the English is (and as
apps for gamers mostly are); „Anführungszeichen"; short forms where a
button has little room; Polyglotic, Plus, Anki, Windows, HSK stay as
they are.
