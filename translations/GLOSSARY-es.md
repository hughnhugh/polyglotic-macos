# Our Spanish words

The app's own terms in Spanish, said one way in every string. **A machine
draft** (polyglotic-hq 294, 2026-11-13, by Claude) for a native speaker's
review: correct a term here first, then every string using it.

How the Spanish is written: neutral Spanish for Spain and Latin America;
"tú", friendly, as the English is; ¿…? and ¡…!; sentence case in buttons;
Polyglotic, Plus, Anki, Windows, HSK stay as they are.
