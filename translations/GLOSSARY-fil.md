# Our Filipino words

The app's own terms in Filipino, said one way in every string. **A machine
draft** (polyglotic-hq 294, 2026-11-13, by Claude) for a native speaker's
review: correct a term here first, then every string using it.

How the Filipino is written: friendly ("mo", "ka"), as the English is;
everyday tech words kept in English as Filipino software and gamers use
them (app, PC, caption, server, deck, hotkey); Polyglotic, Plus, Anki,
Windows, HSK stay as they are.
