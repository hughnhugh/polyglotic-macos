# Our Ukrainian words

The app's own terms in Ukrainian, said one way in every string. **A
machine draft** (polyglotic-hq 294, 2026-11-13, by Claude) for a native
speaker's review: correct a term here first, then every string using it.

How the Ukrainian is written: "ви" (lower case), as Ukrainian software
does; «лапки»; the apostrophe as ’; counts in three forms (1 субтитр, 2
субтитри, 5 субтитрів); short forms where a button has little room;
Polyglotic, Plus, Anki, Windows, HSK stay as they are.
