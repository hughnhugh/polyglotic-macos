# Our French words

The app's own terms in French, said one way in every string. **A machine
draft** (polyglotic-hq 294, 2026-11-13, by Claude) for a native speaker's
review: correct a term here first, then every string using it.

How the French is written: "vous", as French software does; a space
before : ; ! ? and % (a plain space in this draft: a reviewer may make it
non-breaking); « guillemets »; Polyglotic, Plus, Anki, Windows, HSK stay
as they are.
