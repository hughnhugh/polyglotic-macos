# Our Korean words

The app's own terms in Korean, said one way in every string. **A machine
draft** (polyglotic-hq 294, 2026-11-13, by Claude) for a native speaker's
review: correct a term here first, then every string using it.

How the Korean is written: 합니다/하세요 in sentences, short noun forms
on buttons; drawn in Malgun Gothic (`style.SCRIPT_FACES`); Polyglotic,
Plus, Anki, Windows, HSK stay as they are.
