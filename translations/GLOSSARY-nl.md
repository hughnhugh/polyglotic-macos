# Our Dutch words

The app's own terms in Dutch, said one way in every string. **A machine
draft** (polyglotic-hq 294, 2026-11-13, by Claude) for a native speaker's
review: correct a term here first, then every string using it.

How the Dutch is written: "je", friendly, as the English is; 'enkele
aanhalingstekens'; short forms where a button has little room;
Polyglotic, Plus, Anki, Windows, HSK stay as they are.
