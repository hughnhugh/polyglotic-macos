# Our Turkish words

The app's own terms in Turkish, said one way in every string. **A machine
draft** (polyglotic-hq 294, 2026-11-13, by Claude) for a native speaker's
review: correct a term here first, then every string using it.

How the Turkish is written: "sen", friendly, as the English is (a reviewer
may prefer "siz"); "tırnak"; Polyglotic, Plus, Anki, Windows, HSK stay as
they are, with an apostrophe before a suffix (Polyglotic'i).
