# Our Malay words

The app's own terms in Malay (Bahasa Melayu as Malaysia writes it), said
one way in every string. **A machine draft** (polyglotic-hq 294,
2026-11-13, by Claude) for a native speaker's review: correct a term here
first, then every string using it.

How the Malay is written: plain and polite, "anda" for you, the words
Windows and phones use in Malay (Tetapan, Akaun, kemas kini); Polyglotic,
Plus, Anki, Windows, HSK stay as they are. Indonesian has its own file
(`polyglotic_id.ts`); the two differ in many everyday words.
