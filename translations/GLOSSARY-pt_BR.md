(Portugal's Windows reads it too). **A machine draft** (polyglotic-hq 294,
2026-11-13, by Claude) for a native speaker's review: correct a term here
first, then every string using it.

How the Portuguese is written: "você", friendly, as the English is;
"aspas"; Polyglotic, Plus, Anki, Windows, HSK stay as they are.
